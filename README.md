# 小明 · 中文待办智能体

给小明发一句话，就能记下事情、查看清单、标记完成或删除任务。它运行在本机，聊天界面与任务 API 共用一份 JSON 清单，刷新页面或重启服务后任务仍在。

[32 秒网页操作演示（MP4）](docs/demo.mp4)

## 运行

需要 Node.js 24.12 或更高版本。在项目根目录运行以下命令。

```sh
npm ci
npm run dev
```

浏览器打开 <http://127.0.0.1:3000>。下面的全部示例均可直接在本机运行。要让小明借助 DeepSeek 处理更多口语表达，可以按[本地开发指南](GETTING_STARTED.md)配置服务端密钥。

## 验收对话

按顺序发送以下消息。默认清单先展示待办，再展示已完成，编号与当前展示顺序一致。

| 输入             | 可以观察到的结果           |
| ---------------- | -------------------------- |
| 帮我记一下买牛奶 | 出现新增回执               |
| 再记一条取快递   | 第二条待办加入清单         |
| 我有哪些任务？   | 买牛奶和取快递都显示为待办 |
| 牛奶买好了       | 只有买牛奶变为已完成       |
| 取快递这条删掉吧 | 小明确认删除取快递         |
| 再给我看看清单   | 只剩已完成的买牛奶         |

在浏览器刷新页面，再发“查看清单”。也可以停止并重启服务后再查。浏览器里的对话会从头开始，两种情况下任务状态都会保留。任务数据写入 `data/tasks.json`，也可在 `GET /api/tasks` 查看。

## 还可以这样说

| 场景                       | 试一句                                                                                                       |
| -------------------------- | ------------------------------------------------------------------------------------------------------------ |
| 设定截止日、优先级和工作量 | 帮我记一下今天交周报，优先级高，工作量中                                                                     |
| 按到期日查询               | 今天有哪些任务到期？                                                                                         |
| 改期、调整优先级           | 把周报改到明天 ｜ 把周报的优先级改成低                                                                       |
| 查看已经做完的事           | 查看已完成的任务                                                                                             |
| 区分相似任务               | 分别添加“交财务报告”和“交实习报告”，再说“删除报告”。小明会列出候选项，可以回复“第二项”、点选按钮或说“取消”。 |

“今天”按运行服务的电脑本地日期计算。到期查询默认列出未完成任务，日期和优先级显示在清单里。每条消息处理一项操作。

## 自动验证

```sh
npm test
npm run typecheck
npm run lint
npm run fmt:check
npm run build
```

测试使用临时清单，覆盖聊天 HTTP 接口、任务 API、重开服务、歧义选择、日期切换和模型工具调用。模型测试使用模拟响应，可重复运行且无需密钥。更多接口细节见[任务 API](server/openapi.yaml)。本项目基于[词元启明官方模板](https://github.com/TokeNow/todo-agent)。
